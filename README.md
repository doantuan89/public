> **Nếu Ngày Mai note này có trên mạng internet tôi có bị vấn đề gì không ?**
- File and folder by English, thuật ngữ dùng tiếng anh. giải thích ghi chú dùng tiếng việt: `file, directory, hidden file, permission, owner, branch ....`
- Tên folder viết thường, thêm s,  cách nhau bằng dấu gạch giữa -
- Tên file viết thường,  cách nhau bằng dấu gạch giữa -
- Chỉ viết hoa nếu Framework yêu cầu.  
  `vd: React JS: components/ UserCard.jsx LoginForm.jsx`
